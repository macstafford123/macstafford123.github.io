# macstafford123.github.io

My personal portfolio, hosted on GitHub Pages: https://macstafford123.github.io

Built on the [HTML5 UP](https://html5up.net) template (CC BY 3.0, see `LICENSE.txt`), customized with AI-assisted tooling. The live page keeps its layout and styling in a `<style>` block inside `index.html`; the template's stylesheets, Sass sources, and icon fonts are kept in the repo alongside it.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole page: nav, hero, stats bar, about, skills and certifications, projects, experience, contact form, footer. Page styles are in the `<style>` block in the head. |
| `css/`, `sass/`, `webfonts/` | HTML5 UP template stylesheets, Sass sources, and Font Awesome fonts. |
| `images/` | Headshot, the KIRO product photo, and `og-image.png` (the preview card shown when the link is shared). |
| `*.jpg` (root) | Certification badges used in the Certifications section. |
| `favicon.ico` | Browser tab icon. |
| `LICENSE.txt` | HTML5 UP template license (CC BY 3.0). Keep it. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is instead of running Jekyll. |

## Editing

Edit `index.html`, open it in a browser to check it, then commit and push to `main`. GitHub Pages republishes in about a minute. There is no build step.

Rule for content: it has to match my resume, and it only includes public, verifiable information.
