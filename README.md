# macstafford123.github.io

My personal portfolio: one page of plain HTML and CSS, hosted on GitHub Pages.

## Files

| File | What it is |
|---|---|
| `index.html` | All of the page content, in order: nav, intro, experience, projects, skills and certifications, education and contact. |
| `style.css` | All of the styling. Variables at the top, one `@media` block at the bottom for wider screens. |
| `images/` | Headshot, the KIRO product photo, and `og-image.png` (the preview card shown when the link is shared). |
| `favicon.ico` | Browser tab icon. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is instead of running Jekyll. |

## Editing

Edit `index.html` or `style.css`, open `index.html` in a browser to check it, then commit and push to `main`. GitHub Pages republishes in about a minute. There is no build step and no JavaScript.

Rule for content: it has to match my resume, and it never includes employer-internal figures or revenue numbers.
